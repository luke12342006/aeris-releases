# Aeris — versioni

Qui vengono pubblicati gli installer di **Aeris**, la suite di manutenzione del PC.

- **Windows:** scarica `Aeris-Setup-<versione>.exe` dall'[ultima versione](../../releases/latest).
- **Linux (Debian/Ubuntu):** `Aeris_<versione>_amd64.deb`, quando presente.

Aeris controlla questa pagina da solo e si aggiorna automaticamente. Ogni versione ha un
file `latest.json` firmato digitalmente (Ed25519): l'app installa un aggiornamento solo se
la firma e l'impronta SHA-256 dell'installer corrispondono.

Questo repository contiene solo le versioni pubblicate, non il codice sorgente.
